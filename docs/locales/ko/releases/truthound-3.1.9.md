# Truthound 3.1.9 릴리스 노트

## 핵심 변경

Truthound 3.1.9는 3.1.8에서 도입한 A4 Data Docs 보고서의 한국어 locale 표면을
완성합니다. `language="ko"`로 생성한 보고서는 내장 목차, 섹션 제목, 지표 카드,
표 header, 차트 제목, footer 문구, PDF 표지 metadata를 한국어로 렌더링합니다.

## 한국어 보고서 Locale

Data Docs renderer는 이제 `ReportConfig.language`와 내장 i18n catalog를
HTML/PDF 보고서 builder에 연결합니다.

```python
from truthound.datadocs import generate_html_report, export_to_pdf

generate_html_report(
    profile,
    "데이터 품질 분석 보고서",
    theme="light",
    language="ko",
    output_path="report-ko.html",
)

export_to_pdf(
    profile,
    "report-ko.pdf",
    title="데이터 품질 분석 보고서",
    theme="light",
    language="ko",
)
```

사용자가 전달한 제목, 부제, 데이터 출처, 원본 컬럼명은 그대로 유지됩니다. 내장 UI
라벨만 한국어로 지역화됩니다.

## 호환성

기본 locale은 계속 영어입니다. `language`를 지정하지 않은 기존 호출은 기존처럼
영어 라벨을 출력합니다. 공개 theme 정책도 유지됩니다. 공개 theme는 `light`,
`dark`, `minimal`이고, `default`는 숨겨진 `light` alias이며, `professional`과
`modern`은 deprecated alias입니다.

## 검증

Visual smoke suite는 한국어 locale 검증을 포함합니다. `Overview`, `Data
Quality`, `Column Summary`, `Rows`, `Generated by Truthound` 같은 핵심 영어
라벨이 한국어 A4 보고서에 새면 테스트가 실패합니다.
