# Truthound 3.1.10 릴리스 노트

## 핵심 변경

Truthound 3.1.10은 한국어 A4 Data Docs locale 후속 수정을 완료합니다. 파생 지표인
중복 비율 같은 라벨까지 한국어 label map을 통하도록 보강해, `language="ko"`로
생성한 보고서에 핵심 영어 UI 라벨이 다시 노출되지 않게 했습니다.

## 수정 사항

- 개요 영역의 파생 지표 라벨, 특히 중복 비율을 한국어로 렌더링합니다.
- 기본 영어 보고서 표면은 기존 동작 그대로 유지합니다.
- Korean visual smoke coverage를 확장해 `Duplicate Ratio`, `Overview`, `Data
  Quality`, `Column Summary`, `Rows`, `Columns`, `Generated by Truthound` 같은
  라벨이 한국어 보고서 UI 텍스트에 다시 나타나면 테스트가 실패하도록 했습니다.

## 사용법

```python
from truthound.datadocs import generate_html_report, export_to_pdf

generate_html_report(profile, title="데이터 품질 분석 보고서", theme="light", language="ko")
export_to_pdf(profile, "report-ko.pdf", title="데이터 품질 분석 보고서", language="ko")
```

사용자가 전달한 제목, 부제, 데이터 출처, 원본 컬럼명은 그대로 유지됩니다.
Truthound는 내장 보고서 UI와 라벨을 한국어로 지역화합니다.
