# Truthound 3.1.9 Release Notes

## Highlights

Truthound 3.1.9 completes Korean localization for the A4 Data Docs report
surface introduced in 3.1.8. Reports generated with `language="ko"` now render
the built-in table of contents, section headings, metric cards, table headers,
chart titles, footer text, and PDF cover metadata in Korean.

## Korean report locale

The Data Docs renderer now connects `ReportConfig.language` and the built-in
i18n catalog to the HTML/PDF report builder. Use:

```python
from truthound.datadocs import generate_html_report, export_to_pdf

generate_html_report(
    profile,
    "데이터 품질 분석 보고서",
    theme="light",
    language="ko",
    output_path="report-ko.html",
)

export_to_pdf(
    profile,
    "report-ko.pdf",
    title="데이터 품질 분석 보고서",
    theme="light",
    language="ko",
)
```

User-provided titles, subtitles, source names, and original column names are
preserved. Built-in UI labels are localized.

## Compatibility

English remains the default locale. Existing calls without `language` continue
to render English labels. The public theme policy remains unchanged:
`light`, `dark`, and `minimal` are the public themes; `default` remains a hidden
alias for `light`; `professional` and `modern` remain deprecated aliases.

## Validation

The visual smoke suite now includes Korean locale checks that fail if core
English labels such as `Overview`, `Data Quality`, `Column Summary`, `Rows`, or
`Generated by Truthound` leak into Korean A4 reports.
